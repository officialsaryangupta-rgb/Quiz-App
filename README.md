# 🎯 Quiz App

A responsive and interactive Quiz Application built using **HTML, CSS, and JavaScript**. This project allows users to answer multiple-choice questions, view their score at the end, and restart the quiz with a single click.

## ✨ Features

- ✅ Interactive Multiple Choice Questions
- ✅ Dynamic Question Rendering
- ✅ Score Tracking
- ✅ Correct & Incorrect Answer Highlighting
- ✅ Question Counter (e.g. Question 3 of 5)
- ✅ Next Button Navigation
- ✅ Play Again Functionality
- ✅ Responsive User Interface
- ✅ Clean & Beginner-Friendly Code
